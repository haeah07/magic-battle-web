# Magic Battle 기획 원칙 (재미 아이디어 검토 시 기준)

이 문서는 기획 방향 기록입니다. 아직 구현된 규칙이 아닙니다.
현재 UI·턴 전환·드래그 작업에는 게임 규칙을 추가하지 않습니다.

## 유지할 정체성
- 상대가 무엇을 낼지 예측하는 1:1 동시 선택
- 7속성 상성
- MP라는 제한 자원
- 사용한 마법이 필드에 누적되고, 현재 필드가 다음 선택의 가치를 바꿈
- 매 판 전장이 달라지는 경험

## 확정된 방향
1. **방어력(DEF) 중심 전투는 쓰지 않는다.**
   - 방어 투자, DEF 강화 등을 핵심 선택으로 제안하지 않는다.
2. **MP 시스템은 넓은 코스트 범위를 전제로 판단한다.**
   - 현재 테스트 카드는 2~3코스트 위주지만 최종 카드 풀은 더 넓어진다.
   - 초기 기획은 최대 9코스트까지 고려했고, 5코스트 이상의 고비용 마법은 존재할 가능성이 높다.
3. **새 규칙은 유저에게 한두 문장으로 직관적으로 설명할 수 있어야 한다.**
   - `ATK +1`, `DEF +1`, 배율 몇 % 같은 수치 선택을 늘려 복잡성을 만드는 방향은 지양한다.

## 선택의 재미를 찾는 곳
단순한 수치 계산보다 **행동 자체가 달라지는 선택**에서 찾는다. 예:
- 공격 대신 MP 충전
- 일부 정보를 먼저 공개해 블러핑
- 쌓은 필드를 소비해 다른 행동
- 고코스트 마법을 위해 자원을 모음
- 두 마법을 조합해 다른 결과를 만듦

## 이 기준으로 다시 볼 이전 제안
| 이전 제안 | 판단 | 이유 |
|---|---|---|
| 투자 용도 선택 (공격/방어/필드) | 다시 설계 | DEF 중심이고 수치 선택이다 |
| 상성 역전 (투자 시 반감 피해) | 보류 | 수치 위주라 설명이 어렵다 |
| 연계 (코스트 −1, ATK +1) | 다시 설계 | 수치 보너스다 |
| 필드가 카드 기능을 바꿈 | 다시 설계 | 수치 변화가 아닌 행동 변화로 다시 정의해야 한다 |
| 필드 배율 반전 | 보류 | 수치 조정일 뿐 행동이 바뀌지 않는다 |
| 충전 | 유지 | 행동 자체가 달라진다. 고코스트 마법 준비와 연결된다 |
| 예고 카드 (블러핑) | 유지 | 정보 공개 심리전이다 |
| 필드 소비 | 유지 | 쌓은 필드로 다른 행동을 한다 |
| 2장 조합 | 유지 | 조합으로 다른 결과를 낸다 |
| 추론 정보 표시 | 유지 | 규칙 변경 없이 심리전 근거를 준다 |

"다시 설계"는 수치를 빼고 같은 아이디어를 행동 선택으로 바꿀 수 있는지 다시 본다는 뜻입니다.
