# Unity v6 ↔ Web 같은 장면 비교

같은 시드(11), 같은 입력(Unity 참조 스크립트와 동일한 카드 선택·투자 순서), 1/30초 고정 프레임으로 두 버전을 진행해 같은 시점을 찍었습니다.
왼쪽: Unity v6, 오른쪽: Web.

- `compare-1-choose.jpg`: 시작, MP 투자, 화면 넘기기, P2 선택
- `compare-2-battle.jpg`: 공개·충돌·판정·필드 변화·결과 (R1)
- `compare-3-panels.jpg`: 상성표, 상세 정보, 디버그(R5), 게임 종료(R13, 양쪽 모두 P2 승리, P1 HP 0 / P2 HP 7)

참고
- 이 작업 환경에는 Unity 에디터가 없어서, 왼쪽 이미지는 Unity v6 C# 스크립트를 그대로 실행한 뒤 생성된 UI 트리를 그리는 오프라인 참조 렌더러로 만들었습니다. 실제 Unity 화면과는 글꼴 렌더링 같은 미세한 차이가 있을 수 있습니다.
- 연출 중 일부 프레임은 웹이 몇 프레임(약 0.1~0.3초) 앞섭니다. 순서와 결과는 같습니다.
- 데미지 숫자와 "MP 투자" 팝업은 웹에서는 코드대로 포탑·카드 옆에 뜹니다. 참조 렌더러는 이 팝업 위치를 정확히 재현하지 못합니다.
